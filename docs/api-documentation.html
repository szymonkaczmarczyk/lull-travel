Autoryzacja

Endpointy publiczne (/api/stats, /api/stays, /api/destinations, /api/journal, /api/enquiries) nie wymagają żadnych nagłówków ani kluczy. POST /api/enquiries jest ograniczony do 5 żądań na godzinę z jednego adresu IP.

Endpointy /api/admin/* wymagają sesji. Sesję otwiera POST /api/admin/login, który ustawia ciasteczko:

CiasteczkoOpis
lull_adminToken sesji podpisany HMAC-SHA256. Flagi: HttpOnly, SameSite=Strict, Path=/, Secure po HTTPS. Ważny 12 godzin.

Wymagania dla żądań do /api/admin/*:

NagłówekOpis
Cookielull_admin=… — przeglądarka i curl -b dołączają je automatycznie.
Content-Typeapplication/json dla każdego żądania z treścią (POST, PUT, PATCH).
OriginOpcjonalny. Jeśli jest wysłany przy POST/PUT/PATCH/DELETE, musi wskazywać ten sam host co serwer — inaczej 403.

Przykład (curl) — logowanie i pierwsze żądanie z tą samą sesją:

curl -c cookies.txt -H 'Content-Type: application/json' \
  -d '{"email":"admin@example.com","password":"…"}' \
  https://<twoja-domena>/api/admin/login

curl -b cookies.txt https://<twoja-domena>/api/admin/enquiries?status=new

Błąd autoryzacji → HTTP 401, {"error": "Sign in first."}. Gdy panel jest wyłączony (brak ADMIN_EMAIL / ADMIN_PASSWORD na serwerze) → HTTP 503. Logowanie jest ograniczone do 10 prób na 15 minut z jednego IP.

Konwencje i błędy

ZasadaOpis
FormatWszystkie odpowiedzi to JSON w UTF-8 (wyjątek: /api/admin/enquiries.csv).
DatyISO 8601 w UTC, np. 2026-09-28T14:30:41.228Z. Pola dnia bez godziny: YYYY-MM-DD.
CenyLiczby całkowite w walucie z pola currency (EUR, GBP, USD), za noc.
SlugIdentyfikator w adresie: małe litery, cyfry, myślniki (rorbu-nine). Nie zmienia się po publikacji.
ZdjęciaPole image to nazwa pliku bez rozszerzenia. Adresy: /img/card/{image}.jpg (900 px) i /img/card-sm/{image}.jpg (500 px). Puste = brak zdjęcia.
TonyPole tone to para kolorów [ciemny, jasny] w hex, używana jako tło przed wczytaniem zdjęcia.
Maks. rozmiar treści256 kB na żądanie.

Każdy błąd ma ten sam kształt. Pole fields pojawia się tylko przy błędach walidacji:

{"error": "Validation failed.", "fields": {"email": "That email address does not look right."}}
KodKiedy
400Treść żądania nie jest poprawnym JSON-em.
401Brak lub wygasła sesja admina; złe dane logowania.
403Żądanie zmieniające dane z obcego Origin.
404Nie ma takiego zasobu albo endpointu ({"error": "No such endpoint."}).
409Konflikt — np. usuwany region jest wciąż używany przez stays.
413Treść żądania większa niż 256 kB.
422Walidacja nie przeszła; szczegóły w fields (klucz = nazwa pola).
429Przekroczony limit; nagłówek Retry-After i pole retryAfter podają liczbę sekund.
500Błąd serwera. Szczegóły tylko w logu serwera.
503Panel admina wyłączony w konfiguracji serwera.

POST /api/enquiries

POST/api/enquiries

Zapisuje zapytanie z formularza „Plan a trip”. Po zapisie serwer przypisuje zapytanie do skrzynki według reguł routingu i przygotowuje maile (do zespołu i potwierdzenie do klienta). Limit: 5 żądań na godzinę z IP.

Treść żądania (JSON)

PoleWymaganeOpis
nametakImię, 2–120 znaków.
emailtakAdres e-mail, do 200 znaków.
partynieLiczba osób, liczba całkowita 1–12 (domyślnie 2).
destinationnieSlug regionu z /api/destinations. Pusty = bez preferencji.
staynieSlug obiektu z /api/stays. Pusty = klient prosi o shortlistę.
monthnieOrientacyjny termin, dowolny tekst do 40 znaków, np. February 2027.
messagenieWiadomość, do 2000 znaków.

Przykład żądania

POST https://<twoja-domena>/api/enquiries
Content-Type: application/json

{"name": "Ines Aro", "email": "ines@example.com", "party": 2,
 "destination": "lofoten", "month": "February 2027",
 "message": "We would rather be cold than crowded."}

Odpowiedź — błąd walidacji (422)

{"error": "Validation failed.", "fields": {
  "name": "Tell us what to call you.",
  "email": "That email address does not look right.",
  "party": "Party size must be between 1 and 12."
}}

Odpowiedź — przekroczony limit (429)

{"error": "That is a lot of enquiries. Give us an hour to catch up, or email hello@lull.travel.", "retryAfter": 3412}

Odpowiedź — sukces (201)

{
  "id": "LUL-0003",
  "receivedAt": "2026-09-28T15:02:11.482Z",
  "message": "Thank you, Ines Aro. We reply to every enquiry within one working day."
}
KluczOpis
idNumer referencyjny zapytania (LUL- + kolejny numer).
receivedAtCzas zapisu.
messageTekst podziękowania do pokazania klientowi.

Wysyłka maili dzieje się po odpowiedzi — awaria poczty nigdy nie blokuje zapisu zapytania.

Notatki, forward i usuwanie

POST/api/admin/enquiries/{id}/noteswymaga sesji

Dodaje notatkę wewnętrzną do historii. Nic nie jest wysyłane. Treść: {"text": "…"} (1–2000 znaków). Sukces: 201, {"enquiry": {…}}.

POST/api/admin/enquiries/{id}/forwardwymaga sesji

Wysyła kopię zapytania na dowolny adres; handler się nie zmienia. Treść: {"to": "guide@example.com", "note": "…"}.

{
  "enquiry": { …obiekt Enquiry z nowym zdarzeniem "forwarded"… },
  "mail": { …obiekt Mail… }
}
DELETE/api/admin/enquiries/{id}wymaga sesji

Usuwa zapytanie z historią. Maile w outboxie zostają (bez powiązania). Sukces: 204 bez treści; brak zapytania: 404.

        …

    },
    "destinations": { … },
    "journal": { … }
  },
  "images": ["dest-alentejo", "dest-atacama", "stay-rorbu-nine", …]

MetodaŚcieżkaOpis
GET/api/admin/content/{collection}Wszystkie wpisy kolekcji: {"count", "results"}.
GET/api/admin/content/{collection}/{slug}Jeden wpis: {"entry"}.
POST/api/admin/content/{collection}Nowy wpis. Pełny obiekt według schematu, z slug. Sukces 201.
PUT/api/admin/content/{collection}/{slug}Zapis całego wpisu. slug jest ignorowany — nie zmienia się po publikacji.
DELETE/api/admin/content/{collection}/{slug}Usunięcie. 204; 409, gdy region jest używany przez stays.

Przykład żądania

PUT https://<twoja-domena>/api/admin/content/stays/rorbu-nine
Content-Type: application/json
Cookie: lull_admin=…

{ "name": "Rorbu Nine", "destination": "lofoten", "pricePerNight": 340, …pozostałe pola… }

Odpowiedź — błąd walidacji (422)

Odpowiedź — konflikt (409)

{"error": "Still used by 2 stays: Rorbu Nine, Nusfjord Loft."}

Zmiany są widoczne w publicznym API i na stronie natychmiast po zapisie, bez restartu serwera.

Ustawienia: /api/admin/settings

GET/api/admin/settingswymaga sesji

Wszystkie ustawienia CMS, dostępne kolory statusów i placeholdery szablonów.

PUT/api/admin/settings/{key}wymaga sesji

Zapisuje jeden klucz ustawień w całości. Odpowiedź: {"key", "value"}; błędy walidacji — 422 z fields (dla list w formacie "{indeks}.{pole}", np. "0.email").

keyKształt wartości
mail{"fromName", "fromEmail", "replyTo"} — nadawca maili.
mailboxes[{"id", "name", "email"}] — skrzynki. Nie można usunąć skrzynki używanej w routingu.
routing{"notifyOnCreate": bool, "fallback": id, "cc": [id], "rules": [{"destination": slug, "mailbox": id}]}
statuses[{"key", "label", "tone", "final", "notifyTeam", "notifyCustomer", "subject", "body"}] — kolejność ma znaczenie, pierwszy status dostaje każde nowe zapytanie. tone: teal | warm | ok | muted | danger. Nie można usunąć statusu, w którym są zapytania.
templates{"team": {subject, body}, "ack": {enabled, subject, body}, "forward": {subject, body}}

Placeholdery w szablonach

{{ref}} {{name}} {{email}} {{party}} {{month}} {{destination}} {{stay}} {{message}} {{status}} {{assignee}} {{receivedAt}} {{adminUrl}} {{by}} {{note}}
